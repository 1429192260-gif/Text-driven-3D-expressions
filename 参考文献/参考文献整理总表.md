## 第1梯队：与你课题最直接相关

这部分优先级最高，写开题、中期汇报、论文相关工作时应最先引用。

### 1. Towards Rich Emotions in 3D Avatars: A Text-to-3D Avatar Generation Benchmark

- 相关度：极强
- 作用：目前最接近你课题表述的工作，直接讨论 `text-to-3D expression/avatar`
- 你可以怎么用：
  - 说明“文本驱动三维情绪表情生成”是最近才开始被系统研究的方向
  - 说明现有工作更偏 benchmark / 大规模系统，你的工作聚焦于中文 text-only 到参数映射，更轻量、更易复现
- 链接：
  - arXiv abs: [https://arxiv.org/abs/2412.02508](https://arxiv.org/abs/2412.02508)
  - arXiv pdf: [https://arxiv.org/pdf/2412.02508.pdf](https://arxiv.org/pdf/2412.02508.pdf)
  - dblp: [https://dblp.org/rec/journals/corr/abs-2412-02508](https://dblp.org/rec/journals/corr/abs-2412-02508)

### 2. EmoTalk3D: High-Fidelity Free-View Synthesis of Emotional 3D Talking Head

- 相关度：很强
- 作用：说明“情绪可控的 3D talking head” 已成为视觉生成中的热点
- 你可以怎么用：
  - 说明业界更常见的是 `audio/video -> emotional 3D talking head`
  - 反衬你的工作是 `text-only`，输入条件更弱，问题更难
- 链接：
  - arXiv abs: [https://arxiv.org/abs/2408.00297](https://arxiv.org/abs/2408.00297)
  - arXiv pdf: [https://arxiv.org/pdf/2408.00297.pdf](https://arxiv.org/pdf/2408.00297.pdf)

### 3. EmoHead: Emotional Talking Head via Manipulating Semantic Expression Parameters

- 相关度：较强
- 作用：和“语义表情参数”关系很近，适合支撑你现在做的参数空间映射
- 你可以怎么用：
  - 支撑“先预测可解释表情参数，再进行驱动/渲染”这条技术路线
  - 强调你的工作也在做“从高层语义到参数”的映射，只是输入换成中文文本
- 链接：
  - arXiv abs: [https://arxiv.org/abs/2503.19416](https://arxiv.org/abs/2503.19416)
  - arXiv pdf: [https://arxiv.org/pdf/2503.19416.pdf](https://arxiv.org/pdf/2503.19416.pdf)

### 4. EmoCAST: Emotional Talking Portrait via Emotive Text Description

- 相关度：中强
- 作用：直接涉及文本描述驱动情绪肖像生成
- 你可以怎么用：
  - 作为“文本驱动情绪生成”方向的最新旁证
  - 但它更偏 portrait/video synthesis，不完全等于你做的参数预测
- 链接：
  - arXiv abs: [https://arxiv.org/abs/2508.20615](https://arxiv.org/abs/2508.20615)
  - arXiv pdf: [https://arxiv.org/pdf/2508.20615.pdf](https://arxiv.org/pdf/2508.20615.pdf)

## 第2梯队：方法与3D表情建模支撑

这部分不是“文本到表情”的直接论文，但它们定义了你实验依赖的 3D 表情参数空间、表情建模方式和可解释控制思路。

### 1. FLAME: Learning a Model of Facial Shape and Expression from 4D Scans

- 相关度：很强
- 作用：经典 3D 人脸参数模型，很多后续表情参数工作都建立在类似参数化表示上
- 你可以怎么用：
  - 说明三维表情生成通常不会直接生成网格，而是先预测低维、可控的表情参数
  - 为你“输出参数而非直接输出 3D 模型”提供方法合理性
- 链接：
  - 官方页面: [https://is.mpg.de/ps/publications/flame-2017](https://is.mpg.de/ps/publications/flame-2017)
  - 项目页: [https://flame.is.tue.mpg.de/](https://flame.is.tue.mpg.de/)

### 2. DECA: Detailed Expression Capture and Animation

- 相关度：较强
- 作用：说明可动画、可驱动的人脸表达参数可以从视觉中被稳定建模
- 你可以怎么用：
  - 支撑“表情参数空间具备可解释性和可驱动性”
  - 后续如果你要做渲染 demo，也可以把 DECA/FLAME 体系作为接口参考
- 链接：
  - arXiv abs: [https://arxiv.org/abs/2012.04012](https://arxiv.org/abs/2012.04012)
  - arXiv pdf: [https://arxiv.org/pdf/2012.04012.pdf](https://arxiv.org/pdf/2012.04012.pdf)
  - GitHub: [https://github.com/YadiraF/DECA](https://github.com/YadiraF/DECA)

### 3. EMOCA: Emotion Driven Monocular Face Capture and Animation

- 相关度：较强
- 作用：强调“情绪一致性”对 3D 表情建模是一个独立且重要的问题
- 你可以怎么用：
  - 支撑你论文里“仅靠几何/重建误差并不足以表达真实情绪”的论点
  - 说明情绪约束和表情参数预测需要结合
- 链接：
  - arXiv abs: [https://arxiv.org/abs/2204.11312](https://arxiv.org/abs/2204.11312)
  - arXiv pdf: [https://arxiv.org/pdf/2204.11312.pdf](https://arxiv.org/pdf/2204.11312.pdf)
  - MPI 页面: [https://is.mpg.de/en/publications/emoca-cvpr-2022](https://is.mpg.de/en/publications/emoca-cvpr-2022)

### 4. MeshTalk: 3D Face Animation from Speech using Cross-Modality Disentanglement

- 相关度：中强
- 作用：经典 speech-driven 3D facial animation 工作
- 你可以怎么用：
  - 说明跨模态驱动 3D 表情已经有成熟路线
  - 但现有工作主流输入是 speech，不是中文 text-only
- 链接：
  - arXiv abs: [https://arxiv.org/abs/2104.08223](https://arxiv.org/abs/2104.08223)
  - arXiv pdf: [https://arxiv.org/pdf/2104.08223.pdf](https://arxiv.org/pdf/2104.08223.pdf)
  - GitHub: [https://github.com/facebookresearch/meshtalk](https://github.com/facebookresearch/meshtalk)

### 5. Imitator: Personalized Speech-driven 3D Facial Animation

- 相关度：中等
- 作用：代表 speech-driven 3D facial animation 的较新强基线
- 你可以怎么用：
  - 说明已有工作关注“身份保持”和“语音驱动真实性”
  - 反衬你的工作关注“文本语义到表情参数映射”
- 链接：
  - arXiv abs: [https://arxiv.org/abs/2301.00023](https://arxiv.org/abs/2301.00023)
  - arXiv pdf: [https://arxiv.org/pdf/2301.00023.pdf](https://arxiv.org/pdf/2301.00023.pdf)
  - Microsoft Research: [https://www.microsoft.com/en-us/research/publication/imitator-personalized-speech-driven-3d-facial-animation/](https://www.microsoft.com/en-us/research/publication/imitator-personalized-speech-driven-3d-facial-animation/)

### 6. 3DiFACE: Diffusion-based Speech-driven 3D Facial Animation and Editing

- 相关度：中等
- 作用：代表较新的生成式、可编辑 3D facial animation 方法
- 你可以怎么用：
  - 放在“扩展阅读”里，说明这一方向正在向可编辑、可控生成发展
- 链接：
  - arXiv abs: [https://arxiv.org/abs/2312.00870](https://arxiv.org/abs/2312.00870)
  - arXiv pdf: [https://arxiv.org/pdf/2312.00870.pdf](https://arxiv.org/pdf/2312.00870.pdf)

## 第3梯队：文本情绪识别与数据支撑

这部分用于支撑你当前 text-only 前端的合理性，也能服务你论文里的“文本情绪分析”相关工作。

### 1. Johnson8187 / Chinese-Emotion-Small

- 相关度：很强
- 作用：你当前实验真正接入使用的中文情绪识别前端
- 你可以怎么用：
  - 在论文里作为“外部中文情绪先验模型”说明
  - 重点写：我们不是直接依赖黑盒输出，而是在其上加入任务适配规则 `rules_v4`
- 链接：
  - 模型页: [https://huggingface.co/Johnson8187/Chinese-Emotion-Small](https://huggingface.co/Johnson8187/Chinese-Emotion-Small)
  - 文件页: [https://huggingface.co/Johnson8187/Chinese-Emotion-Small/tree/main](https://huggingface.co/Johnson8187/Chinese-Emotion-Small/tree/main)

### 2. SMP2020-EWECT 相关数据说明

- 相关度：较强
- 作用：中文微博情绪分类的重要公开评测背景
- 你可以怎么用：
  - 支撑“中文微博文本是情绪识别的重要真实场景”
  - 说明你后续使用微博数据扩充并不是凭空构造
- 链接：
  - 官方站点: [https://smp2020ewect.github.io/](https://smp2020ewect.github.io/)

### 3. A Novel Approach for Multiclass Sentiment Analysis on Chinese Social Media with ERNIE-MCBMA

- 相关度：中强
- 作用：使用 SMP2020-EWECT 的较新中文情绪分类论文
- 你可以怎么用：
  - 支撑“中文微博情绪分类仍是活跃研究问题”
  - 也可用于补充前沿相关研究
- 链接：
  - Nature 页面: [https://www.nature.com/articles/s41598-025-03875-y](https://www.nature.com/articles/s41598-025-03875-y)
  - PMC 页面: [https://pmc.ncbi.nlm.nih.gov/articles/PMC12119951/](https://pmc.ncbi.nlm.nih.gov/articles/PMC12119951/)

### 4. Textual Emotion Classification using MPNet and Cascading Broad Learning

- 相关度：中等
- 作用：同样是基于 SMP2020-EWECT 的文本情绪识别研究
- 你可以怎么用：
  - 作为“中文文本情绪识别方法线”的补充文献
- 链接：
  - ScienceDirect: [https://www.sciencedirect.com/science/article/abs/pii/S0893608024005069](https://www.sciencedirect.com/science/article/abs/pii/S0893608024005069)

### 5. GoEmotions: A Dataset of Fine-Grained Emotions

- 相关度：中等
- 作用：国际上影响力很大的细粒度文本情绪数据集
- 你可以怎么用：
  - 支撑“细粒度情绪识别是一个独立研究趋势”
  - 可用于说明你把 `concern / disgust / bored` 等细粒度类别纳入实验是合理的
- 链接：
  - ACL 页面: [https://aclanthology.org/2020.acl-main.372/](https://aclanthology.org/2020.acl-main.372/)
  - PDF: [https://aclanthology.org/2020.acl-main.372.pdf](https://aclanthology.org/2020.acl-main.372.pdf)

### 6. EmoTweet-28: A Fine-Grained Emotion Corpus for Sentiment Analysis

- 相关度：中等
- 作用：早期细粒度社交文本情绪语料
- 你可以怎么用：
  - 作为细粒度情绪标注历史背景
- 链接：
  - ACL 页面: [https://aclanthology.org/L16-1183/](https://aclanthology.org/L16-1183/)

### 7. Uncovering the Limits of Text-based Emotion Detection

- 相关度：中等
- 作用：从评估角度说明文本情绪识别本身存在上限和歧义
- 你可以怎么用：
  - 支撑你论文中“弱情绪、边界情绪难识别”的分析
  - 也能解释为什么 text-only 到表情参数并不是一个容易任务
- 链接：
  - ACL 页面: [https://aclanthology.org/2021.findings-emnlp.219/](https://aclanthology.org/2021.findings-emnlp.219/)
  - PDF: [https://aclanthology.org/2021.findings-emnlp.219.pdf](https://aclanthology.org/2021.findings-emnlp.219.pdf)
